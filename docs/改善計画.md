## 1. 進め方の決まりごと

- **「手作り」の意味**: ユーザーが作るのではなく、Claude Code が集中して設計・制作する。要所はユーザーとすり合わせる(画像を見せて選んでもらう、案を2〜3個出して決めてもらう)。
- **参考作品**: Kingdom Rush、Bloons TD 6、Plants vs. Zombies、Rush Royale、Orcs Must Die!、Poppy Playtime。参考にするのは仕組みと雰囲気だけ。キャラクター・名前・絵柄・ステージはまねない。
- **確認の仕方**: 変更のたびに `npm run typecheck`・`npm run build`・`npm run sim` を通し、画面は撮影して確認する。スマホ横向きでの操作確認を必ず入れる。
- **スマホ前提**: 操作を増やさない。片手で迷わず遊べることを優先する。

### 3. タワー・戦略の深さ

| No. | 項目 | 優先度 | 状態 | 内容 |
| --- | --- | --- | --- | --- |
| 3-1 | 攻撃する相手の優先順の切り替え | — | 不採用 | 操作が複雑になるため。 |
| 3-2 | 強化の分岐を増やす | ★★ | 採用 | 同じ塔でも育て方で役割が変わるようにする。 |
| 3-3 | 塔どうしの組み合わせ効果 | ★★ | 採用 | 支援タワー、凍らせて砲台で割るなどの連携。 |
| 3-4 | 合体・進化の要素 | — | 不採用 | |
| 3-5 | 兵士の操作感 | ★ | 一部採用 | 集合地点の操作の改善のみ。兵士の個別強化は不採用。 |
| 3-6 | **タワーの独自性(新規)** | ★★★ | 要すり合わせ | 今の塔はキングダムラッシュと同じ構成(弓・兵舎・魔法・砲台)。バランスと「役割がひと目で分かる」ことは保ったまま、鶏の世界ならではの塔に作り替える。下の「案」をたたき台にユーザーと決める。 |

**3-6 のたたき台(案)**: 役割(遠距離の単体・足止め・防御無視・範囲)は残し、見た目と仕組みを鶏の世界に寄せる。

- 遠距離の単体 → 例: 「羽ばたき投げ」の見張り台(羽根の矢・卵つぶて)
- 足止め → 例: 「鶏小屋」の守備隊(ひよこが道に巣を作って足止め)
- 防御無視 → 例: 「虹色の卵」の祭壇(魔法の卵の光)
- 範囲 → 例: 「卵の大砲」/「雷トサカ」(爆発・連鎖)
- 専門タワー8種も同じ考え方で、名前・見た目・能力の組み合わせを独自のものに作り直す。
