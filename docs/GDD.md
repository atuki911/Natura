# Natura 企画書(GDD)

版: 0.1(試作) / 更新: 2026-11-05

## 一言で

棒人間の兵を出して、湧き続ける怪物の波から城を守る、横一本道の城防衛ゲーム。1回 6〜8 分、ブラウザで遊べる。

## 世界観

- **緑の王国ナトゥラ**: 小さな城と、青い鉢巻きの棒人間たち。紋章は金の葉。
- **穢れ(Blight)**: 右の地平から地面を紫に染めながら迫る。穢れの砦の門から、ぷよぷよした粘体や影や目玉の怪物が湧き出る。
- 調子: 明るく、少しとぼけた漫画調。怖さより「わちゃわちゃ」。血は出さず、敵は紫の粘液になって弾ける。

## 遊びの核

1. ゴールド(時間で増える・敵を倒すと入る)とマナ(時間で増える)をためる。
2. 下のカードから兵を出す。兵は右へ進み、最前線で敵と戦う。
3. 道沿いの3か所の土台にタワーを建てる。
4. 回復と隕石の特殊能力を、ここぞという時に使う。
5. 休憩中に「次のウェーブ」を押すと早く始まり、残り時間に応じたボーナスが入る(攻めの選択)。

勝ち: 全ウェーブを防ぐ。負け: 城の体力が 0。星は城の残り体力で 1〜3 個。

## 相性(選ぶ理由を作る)

| 敵 | 特徴 | 効く手 |
|---|---|---|
| 粘体(blightling) | ふつう | なんでも |
| 小鬼(gnasher) | 速くて脆い | 剣士・大砲 |
| 牙獣(tuskbeast) | 鎧で物理ダメージを45%減らす | 魔法使い(鎧無視)・隕石 |
| 影(wisp) | 空を飛ぶ。近接攻撃が届かない | 弓兵・弓の塔・魔法使い |
| 転がり目玉(rollereye) | 最初の一撃が3倍で吹き飛ばす | 安い剣士を前に立てる |
| 泥沼の大口(mireMaw、ボス) | 範囲の叩きつけ、雑魚を吐き出す | 魔法使い・隕石・数で押す |

| 味方 | 値段 | 役 |
|---|---|---|
| 剣士 | 50G | 前で受け止める |
| 弓兵 | 75G | 空も撃てる遠距離 |
| 魔法使い | 60G+40マナ | 範囲・鎧無視。マナを能力と取り合う |
| 爆弾兵 | 120G | 突っ込んで自爆、範囲大 |
| 弓の塔 | 250G | 空と地上、単体 |
| 大砲 | 380G | 地上のみ、範囲 |
| 回復 | 60マナ | 兵を50%、城を8%回復 |
| 隕石 | 90マナ | 場所を選んで範囲260ダメージ |

## 規模の目標(本格版)

| 項目 | 試作(今) | 本格版 |
|---|---|---|
| ステージ | 1(10ウェーブ) | 4地域 × 各10ウェーブ前後 + エンドレス |
| 味方ユニット | 4 | 12(強化で見た目も変わる) |
| 敵 | 6(ボス1) | 25(ボス6) |
| タワー | 2 | 5(各3段階の強化) |
| 特殊能力 | 2 | 6 |
| ステージ外の成長 | なし | 星で解放する強化ツリー |

## 数字の決め方

`npm run balance` で自動プレイを回して決める。目安は「ふつうの腕前(standard)で勝率 60〜85%」「剣士だけ連打では勝てない」「何もしないと必ず負ける」。

現在(ステージ1): standard 70%(勝った時の城の残り 66%)、swordOnly 0%、idle 0%。
