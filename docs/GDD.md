# Natura 企画書(GDD)

版: 0.2 / 更新: 2026-11-05(独自性探索の第1回の結果を反映)

## 一言で

**倒れた兵が木になり、戦場が森になっていく**城防衛ゲーム。棒人間の兵を出して穢れの怪物の波を防ぐ。兵が倒れた場所には、兵種ごとに違う木が生え、地形として戦い続ける。

独自性の見つけ方と、この案を選んだ理由は `exploration/round-1/` にある(60案 → 12案 → 3本の試作 → 決定)。

## 世界観

- **緑の王国ナトゥラ**: 小さな城と、青い鉢巻きの棒人間たち。紋章は金の葉。
- **穢れ(Blight)**: 右の地平から地面を紫に染めて迫る。門から粘体・影・目玉・蛾などの怪物が湧く。
- **兵は倒れても大地に還り、木になって王国を守り続ける。** 木の周りの地面は緑に戻る。
- 調子: 明るく、少しとぼけた漫画調。血は出さず、敵は紫の粘液になって弾ける。

## 遊びの核

1. ゴールド(時間・撃破・収穫)とマナ(時間・収穫)をためる。
2. 下のカードから兵を出す。兵は右へ進み、最前線で戦う。
3. **戦って倒れた兵は、その場所に木を残す**(戦わずに倒れた兵は残さない)。
4. **実った木をなでると収穫**(ゴールド・マナ)。長押しで引き抜くとゴールドになる。
5. タワーと特殊能力(回復は木も治す、隕石)で支える。
6. 休憩中に「次のウェーブ」を押すと早く始まり、ボーナスが入る。

勝ち: 全ウェーブを防ぐ。負け: 城の体力が 0。星は城の残り体力で 1〜3 個。

## 兵と、倒れた後の木

| 兵 | 値段 | 役 | 倒れると | 木の役 |
|---|---|---|---|---|
| 剣士 | 50G | 前で受け止める | 茨 | 地上の敵の足を止め、とげで刺す |
| 弓兵 | 75G | 空も撃てる遠距離 | 見張りの木 | 近づく敵を撃つ。金の実がなる |
| 魔法使い | 60G+40マナ | 範囲・鎧無視 | 魔法の花 | 蜜をためる。摘むとマナと金 |
| 爆弾兵 | 120G | 自爆・範囲大 | 種の莢 | 敵が近づくとはじける |

木は同時に8本まで。近くに同じ種類の木があれば、新しく生えずにその木が太る。木は時間と、穢れに踏まれることで枯れていく。

## 敵

| 敵 | 特徴 | 効く手 |
|---|---|---|
| 粘体 | ふつう | なんでも |
| 小鬼 | 速くて脆い | 剣士・茨・大砲 |
| 牙獣 | 鎧で物理ダメージを減らす | 魔法使い・隕石 |
| 影 | 空を飛ぶ | 弓兵・見張りの木・魔法使い |
| 転がり目玉 | 最初の一撃が重い | 安い剣士を前に |
| 蛾(地域2〜) | 空を飛び、木をかじって枯らす | 弓兵・見張りの木 |
| 地虫(地域2〜) | 地中を進み、茨に止められない | 弓兵・塔 |
| 泥沼の大口(ボス) | 叩きつけ、粘体を吐く | 魔法使い・隕石 |
| 胞子の母(ボス) | 周りの木を枯らし、蛾を産む | 遠くから魔法・木を前に出さない |
| 穢れの心臓(最後のボス) | 木を枯らし、怪物を順番に産む | すべて |

## 数字の決め方

- 作戦ごとの勝率の差: `node tools/metrics.ts 30`(目安 25 ポイント以内)
- ステージの難しさ: `node tools/tune.ts <ステージ> <目標の勝率>` で敵の強さの倍率を探し、`npm run balance -- 30 all` で確かめる。
- 自動プレイは人より上手い(収穫を逃さない)ので、人には少し難しく感じる可能性がある。試遊の結果で下げる。
