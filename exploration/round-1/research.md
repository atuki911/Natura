# 段階1: 市場調査(2026-11-05、調査エージェントの報告の要約)

## 今の試作版が寄っている作品(差別化の要)

- **決まった3枠のタワー + 回復と流星** → Kingdom Rush に寄る
- **時間で金が貯まる左右対称のレーン** → Age of War・War of Sticks に寄る

## 使い古された仕組み(選抜の足切りで照合する)

| 仕組み | 例 |
|---|---|
| 時代・形態の進化 | Age of War、にゃんこ大戦争 |
| 鉱夫・財布で収入を強化 | War of Sticks、Stick War、にゃんこ大戦争 |
| ランダム召喚と合成 | Rush Royale、Lucky Defense |
| ステージ間の強化の木 | ほぼ全作 |
| 放置型の城防衛 | Grow Castle、Idle 系 |
| 決まった塔の枠 + 流星・援軍 | Kingdom Rush |
| 塔の強化の分岐 | Bloons TD |
| ローグライクで塔・遺物を選ぶ | Rogue Tower、Nordhold |
| 塔を縦に積む | Tower Crush |
| 兵のスキン集め | Stickman Kingdom Clash |

## このジャンル(横一本道)でまだ少なそうな方向(調査役の見立て)

- 戦線の位置そのものを資源にする(綱引き)
- 死んだ兵・敵の残骸が次の何かに使える
- 地形・天候が変わる
- 兵の後退・隊列・合図などの指揮
- 敵がこちらの構成に合わせて作戦を変える
- 敵の進む道や時間に手を加える

## 遊び手が喜ぶ見せ場

- 組み合わせが噛み合って「壊れた強さ」になる瞬間
- 連鎖する雷・属性反応が広がる様子
- ぎりぎりで持ちこたえる
- 自分の判断の結果を眺めて確かめられる

## Web ポータルの条件

- 1クリック以内でゲームに入る。説明は飛ばせ、文字より絵で見せる。
- 10秒で楽しいかが分かれ目。最初の1分を抜ける人が半分未満なら問題。
- 800x450 の iframe でも文字が読める。PC 横画面が前提。
- Esc・Ctrl+W を使わない。独自の全画面ボタンは禁止(CrazyGames)。
- PEGI 12 相当。読み込みは軽く(20MB 以下、できれば 8MB 以下)。
