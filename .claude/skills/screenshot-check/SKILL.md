# 画面を撮って確かめる

1. `npm run screenshot` を実行する(タイトル・序盤・中盤・ボス戦を `screenshots/` に撮る)。特定の場面は `npm run screenshot -- --url "?autoplay&wave=6&speed=2" --wait 10000 --name mid`。
2. 撮った画像を Read で開いて見る。確かめること:
   - 操作盤の文字やアイコンが重なっていない・はみ出していない。
   - 兵と敵の足が道の上にあり、浮いて・沈んでいない。重なり順(手前が上)が正しい。
   - エフェクトが出ていて、白い四角(テクスチャ切れ)が無い。
   - 背景の境目に不自然な直線や四角が無い。
3. ブラウザのエラーが出たら(コマンドが失敗で終わる)、先に直す。
4. 見つけた崩れを直し、もう一度撮って、直る前と後の画像を並べて報告する。
