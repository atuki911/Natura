# バランスを調整する

1. `npm run balance -- 60` で今の勝率を測り、記録する。
2. 目安と比べる: standard 60〜85%(勝った時の城の残り 50〜80%)、swordOnly ほぼ 0%、idle 必ず 0%。負けるウェーブが1か所に偏っていないかも見る。
3. 直すのは `src/data/` の数字だけ。1回に変える数字は1〜2個にして、毎回測り直す。
4. 特定のウェーブを詳しく見たい時は、`tools/balance.ts` を参考に、そのウェーブから始める検証を書いてよい(`debugJumpWave` 命令)。
5. 結果を変更前後の表で報告し、`docs/GDD.md` の「現在」の数字を更新する。
